# Página Web de Restaurante

Proyecto de una página web de un restaurante ficticio desarrollado en 2026 para la materia Desarrollo de Aplicaciones.

## Descripción

El proyecto consiste en el desarrollo de un sitio web para un restaurante ficticio. La página permite presentar el menú del establecimiento y organizar diferentes categorías de productos de manera interactiva.

El objetivo fue aplicar los conocimientos adquiridos durante la materia en el desarrollo y diseño de una aplicación web.

## Tecnologías utilizadas

- HTML
- CSS

## Características

- Página principal del restaurante.
- Secciones para diferentes tipos de productos.
- Diseño de la interfaz utilizando HTML y CSS.

## Contexto académico

Proyecto realizado durante 2026 en el marco de la materia Desarrollo de Aplicaciones.
